# 하루목록 — 한국어 할 일 관리 웹앱

HTML, CSS, JavaScript만으로 만든 간단한 할 일 관리 앱입니다.

## 기능

- 할 일 추가
- 완료 체크
- 삭제
- 새로고침해도 내용 유지 (`localStorage`)
- 모바일 친화적 디자인

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 디자인
- `app.js` — 동작(추가/체크/삭제/저장)
- `설치하기.bat` — Windows 설치 프로그램 (바탕화면에 설치)
- `제거하기.bat` — Windows 제거 프로그램

## Windows에서 바탕화면에 설치하기

1. 이 폴더의 `설치하기.bat`을 더블클릭합니다.
2. 검은 창이 뜨면 안내를 읽고 아무 키나 누릅니다.
3. 바탕화면에 **하루목록** 폴더와 **하루목록** 바로가기가 생깁니다.
4. 바탕화면의 **하루목록** 바로가기를 더블클릭하면 앱이 실행됩니다.

제거하려면 `제거하기.bat`을 실행하거나, 바탕화면의 `하루목록` 폴더 안에 있는 `제거하기.bat`을 실행하세요.

## 설치 없이 바로 실행하기

1. `index.html` 파일을 더블클릭하거나 브라우저로 드래그해서 엽니다.
2. 또는 VS Code의 Live Server 등으로 `index.html`을 엽니다.

별도 프로그램 설치나 서버가 없어도 바로 사용할 수 있습니다.

# 하루목록 — 한국어 할 일 관리 웹앱

HTML, CSS, JavaScript만으로 만든 간단한 할 일 관리 앱입니다.

## 기능

- 할 일 추가
- 완료 체크
- 삭제
- 새로고침해도 내용 유지 (`localStorage`)
- 모바일 친화적 디자인

## 파일 구성

- `index.html` — 화면 구조
- `style.css` — 디자인
- `app.js` — 동작(추가/체크/삭제/저장)

## 실행 방법

1. 이 폴더에 `index.html`, `style.css`, `app.js`가 있는지 확인합니다.
2. `index.html` 파일을 더블클릭하거나, 브라우저로 드래그해서 엽니다.
3. 또는 VS Code의 Live Server 등으로 `index.html`을 엽니다.

별도 설치나 서버가 없어도 바로 사용할 수 있습니다.
